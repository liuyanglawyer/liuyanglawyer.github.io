# 刘洋律师的网络犯罪辩护站

一个零构建、可直接托管的个人博客站点。围绕网络犯罪辩护主题，包含文章列表、文章详情、标签分类、关于页面、Markdown 渲染、后台登录与内容管理，数据层同时支持**腾讯云开发 CloudBase（云数据库 + 云存储 + 账号认证）**与**浏览器本地离线存储**两种模式。

## 目录结构

```
blog/
├── index.html                  # 单页应用入口（hash 路由）
├── assets/
│   ├── css/style.css           # 浅色主题样式
│   ├── vendor/                 # 本地依赖，无需联网
│   │   ├── marked.min.js       # Markdown 解析
│   │   ├── highlight.min.js    # 代码高亮
│   │   ├── github.min.css
│   │   └── cloudbase.full.js   # 腾讯云开发 Web SDK（打包为全局脚本，按需加载）
│   └── js/
│       ├── util.js             # DOM/日期/存储/图片压缩工具
│       ├── config.js           # 站点配置与云端连接参数
│       ├── seed.js             # 内置内容 73 篇（见「内容来源与栏目」）
│       ├── store.js            # 统一数据层（云端/本地双实现）
│       ├── md.js               # Markdown 渲染 + 目录 + 安全清洗
│       ├── views.js            # 前台页面
│       ├── admin.js            # 后台管理 + 登录
│       └── app.js              # 路由与引导
```

## 本地预览

任意静态服务器均可，例如：

```bash
cd blog
python3 -m http.server 8080
# 浏览器打开 http://localhost:8080
```

> 直接双击 `index.html` 也能打开，但此时浏览器不允许使用 localStorage，文章将无法持久化（页面会退化为临时内存模式）。建议用本地服务器访问。

## 页面与路由

| 路由 | 内容 |
| --- | --- |
| `#/` | 首页：Hero + 搜索 + 文章卡片 + 标签云 + 分页 |
| `#/post/:slug` | 文章详情：Markdown 渲染、代码高亮、右侧悬浮目录、上一篇/下一篇 |
| `#/tags` | 全部标签 + 全站文章归档表 |
| `#/tag/:tag` | 按标签过滤 |
| `#/category/:name` | 按分类过滤 |
| `#/about` | 关于律师：简介、业务范围、执业信息、联系与委托说明 |
| `#/admin` | 后台：登录 → 文章列表 / 写稿 / 素材库 / 云端接入 / 站点设置 |

## 后台使用

1. 打开 `#/admin`，本地模式默认账号 **admin** / **lb2026**（登录后可在「站点设置」里改）。
2. 「文章列表」页可新建、编辑、发布/转草稿、删除文章，以及导出/导入 JSON 备份。
3. 「写新文章」页左右分栏：左侧表单 + 右侧 Markdown 源码/预览切换，工具栏可一键插入标题、表格、代码块，也可直接上传图片自动插入 `![]()`。
4. 「素材库」页上传图片后可一键复制链接，填入文章封面或正文。
5. 「站点设置」页修改站点名称、律师资料、业务范围、联系方式等（保存在浏览器本地，随站点一起生效）。

## 接入云端（腾讯云开发 CloudBase）

站点默认运行在**本地离线模式**（文章存 localStorage、图片存 IndexedDB）。接入后的效果：

- 文章数据 → 云数据库集合
- 图片附件 → 云存储
- 登录认证 → CloudBase 账号体系（邮箱 / 用户名密码）

### 配置步骤

1. 开通 [腾讯云开发 CloudBase](https://tcb.cloud.tencent.com/)，新建环境，记录**环境 ID**。
2. 在「数据库」新建集合（默认名 `posts`），安全规则改为：

   ```json
   {
     "read": true,
     "write": "doc._openid == auth.openid"
   }
   ```

   > 不改这一步，未登录的访客读不到文章，站点会自动降级为本地模式。

3. 在「登录鉴权」中开启**邮箱登录**或**用户名密码登录**，并在「用户管理」里注册本站管理员账号。
4. 在「安全配置 → WEB 安全域名」中加入站点域名，否则浏览器会拦截请求。
5. 打开 `#/admin/cloud`，填入环境 ID，点击「保存并连接」。顶部状态条出现「已接入云端：xxx」即成功。

接入失败时不会白屏，系统会自动降级到本地模式并在后台提示具体原因。

> 性能说明：`cloudbase.full.js` 只在开启云端模式时由 `store.js` 动态注入，纯浏览不发这个请求。首屏固定加载约 230KB（Markdown + 代码高亮 + 本站脚本）。

律师简介（执业机构、职务、教育背景、著述、代理案例）取自原站「律师简介」页，已写入 `config.js` 并在「关于」页展示；2026 年新增的社会职务与受聘信息已同步补充。

**关于日期**：
- 微信文章按公众号实际发布时间写入（精确到日）；
- 原站技术趋势按标注年月（2024-07 ~ 2025-03）、典型案例按标注年份（2022–2024）写入；
- 原站未标注发布时间的专业文章与合规报告，以及 3 篇原文页已不可完整抓取的微信文章（分享会、法大鉴定所参观、侵犯公民个人信息案取保），日期为按内容顺序推断的占位值，如需精确请在「后台 → 文章列表」中修改。

**关于图片**：微信文章正文图片直接引用 `mmbiz.qpic.cn` 原图外链（已过滤公众号模板装饰图与动图）。离线打开时图片无法显示，文字内容不受影响。若需要完全离线，可在后台「素材库」重新上传图片后替换正文链接。

## 内容与隐私说明

- 首次打开时内容由 `seed.js` 写入本地库（键名 `lb_posts_v4`）。更新 seed 内容后如需强制重载，可在后台删除后重新导入，或清空该 localStorage 键。
- 早期版本内置的 6 篇示例文章已移除，备份见 `_backup/seed-示例文章备份-20261031.js`；导入微信文章前的 35 篇版本备份见 `_backup/seed-35篇-20261101.js`。
- 本地模式下所有数据保存在**本人浏览器**，不上传任何服务器；清空浏览器数据会丢失文章，建议定期用「导出 JSON」备份。
- 律师资料中的联系电话、邮箱来自原站公开信息；如需变更请在「站点设置」中修改后再对外发布。
